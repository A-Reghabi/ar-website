# پورتفولیوی علیرضا رقابی

لندینگ‌پیج فارسی و انگلیسی با زمینهٔ سفید و رنگ‌های آبی و زرد. محتوا بر اساس رزومهٔ ارائه‌شده نوشته شده و عکس اصلی بدون تغییر استفاده شده است. سایت بدون نصب پکیج یا مرحلهٔ build روی GitHub Pages اجرا می‌شود.

## فایل‌ها

- `index.html` ساختار صفحه و لینک‌های تماس و رزومه.
- `styles.css` ظاهر صفحه، چیدمان موبایل و راست‌به‌چپ.
- `fonts.css` تعریف فونت وزیر و `assets/fonts` فایل WOFF2 و مجوز آن.
- `app.js` متن‌های فارسی و انگلیسی، انتخاب زبان، منوی موبایل و کپی ایمیل.
- `motion.css` جلوه‌های متحرک، ورود بخش‌ها، کارت‌های سه‌بعدی و واکنش دکمه‌ها.
- `motion.js` شبکهٔ سه‌بعدی Canvas، تعامل با موس، کنترل حرکت‌ها و نوار پیشرفت اسکرول.
- `Profile.jpg` عکس پروفایل.
- `Alireza Reghabi AI Resume.pdf` فایل رزومهٔ قابل دریافت.
- `CNAME` دامنهٔ `reghabi.ir`.
- `.nojekyll` برای انتشار مستقیم فایل‌های استاتیک.
- `robots.txt` و `sitemap.xml` تنظیمات اولیهٔ موتورهای جست‌وجو.
- `DEPLOYMENT.fa.md` راهنمای انتشار روی GitHub Pages و اتصال دامنه در Cloudflare.

## پیش‌نمایش

برای دیدن صفحه، `index.html` را در مرورگر باز کنید. برای بررسی قابلیت کپی ایمیل و اجرای صفحه با سرور محلی، در همین پوشه دستور زیر را اجرا کنید و `http://localhost:4173` را باز کنید.

```powershell
python -m http.server 4173
```

## ویرایش محتوا

فایل‌های CSS و JavaScript با یک پارامتر نسخهٔ تازه در هر بار باز شدن یا رفرش صفحه بارگذاری می‌شوند. بنابراین رفرش معمولی نسخهٔ جدید این فایل‌ها را دریافت می‌کند و نیازی به Ctrl+F5 یا تغییر دستی شمارهٔ نسخه نیست. این فایل‌های کوچک در هر بار باز شدن صفحه دوباره دریافت می‌شوند؛ عکس و فونت همچنان می‌توانند از کش استفاده کنند. آماده‌شدن انتشار GitHub Pages و به‌روزرسانی کش خود صفحهٔ HTML همچنان ممکن است کمی زمان ببرد.

متن‌ها در دو بخش `en` و `fa` در `app.js` قرار دارند. متن انگلیسی اولیه در `index.html` هم موجود است تا صفحه بدون JavaScript قابل خواندن باشد. هنگام تغییر محتوا هر دو را به‌روز کنید.

لینک GitHub، LinkedIn و فایل رزومه در `index.html` قرار دارند. برای تغییر ایمیل، آدرس‌های `mailto:` در `index.html` و رشتهٔ ایمیل در تابع کپی در `app.js` را ویرایش کنید. نام فایل عکس و PDF را ثابت نگه دارید یا مسیرهایشان را در HTML تغییر دهید.

زبان پیش‌فرض انگلیسی است و انتخاب فارسی یا انگلیسی در مرورگر همان بازدیدکننده ذخیره می‌شود. تاریخ‌ها در هر دو نسخه بر مبنای تقویم میلادی هستند. نسخهٔ فارسی از فونت وزیر استفاده می‌کند. فایل متغیر WOFF2 نسخهٔ ۳۰.۱.۰ همراه سایت میزبانی می‌شود و به سرویس فونت خارجی وابسته نیست. منبع فونت، مخزن رسمی [وزیر](https://github.com/rastikerdar/vazirmatn/tree/v30.1.0) است و مجوز آن در `assets/fonts/OFL.txt` قرار دارد.

اگر دامنه عوض شد، `CNAME`، آدرس‌های canonical و Open Graph در `index.html`، `robots.txt` و `sitemap.xml` را هم به‌روز کنید.

فرم تماس و سرور هوش مصنوعی در این سایت وجود ندارد. دکمهٔ تماس برنامهٔ ایمیل بازدیدکننده را باز می‌کند. نمودار بخش MegaChat یک تصویر توضیحی است و معماری واقعی محصول را ادعا نمی‌کند.

## انیمیشن‌ها

شبکهٔ اطراف عکس به‌صورت سه‌بعدی می‌چرخد و به حرکت موس واکنش نشان می‌دهد. عکس و برچسب‌ها شناور هستند. کارت‌های تجربه با حرکت موس زاویه و انعکاس نور می‌گیرند. بخش‌ها هنگام اسکرول ظاهر می‌شوند و نمودار هوش مصنوعی سیگنال‌های متحرک دارد. نوار ابزارها پیوسته حرکت می‌کند و دکمه‌ها به موقعیت موس واکنش نشان می‌دهند.

دکمهٔ کنار انتخاب زبان، حرکت‌های پیوسته را متوقف می‌کند و انتخاب کاربر ذخیره می‌شود. تنظیم کاهش حرکت دستگاه نیز رعایت می‌شود. روی دستگاه‌های لمسی، حرکت وابسته به موس اجرا نمی‌شود. شبکهٔ Canvas در حالت عادی با سقف ۳۰ بار رسم در ثانیه و هنگام تعامل موس با سقف ۶۰ بار رسم اجرا می‌شود. وقتی بخش اول خارج از دید یا تب پنهان است، حلقهٔ رسم متوقف می‌شود. رویدادهای موس فقط موقعیت هدف را ذخیره می‌کنند؛ حرکت عکس و شبکه در حلقهٔ رسم هماهنگ می‌شود.

فایل‌های `motion.css` و `motion.js` را همراه بقیهٔ فایل‌ها بارگذاری کنید. انیمیشن‌ها کتابخانه یا سرویس خارجی ندارند و همان روش انتشار GitHub Pages کافی است.

آزمون رفتار رویدادهای موس، زمان‌بندی رسم و توقف انیمیشن را با دستور زیر اجرا کنید. این آزمون کد اصلی را با یک محیط کنترل‌شده اجرا می‌کند و نرخ فریم سخت‌افزار یا هزینهٔ واقعی رسم مرورگر را اندازه نمی‌گیرد.

```powershell
node --test tests/motion-performance.test.cjs
```
